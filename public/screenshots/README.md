# Screenshots Directory

Place your project screenshots in this directory.

## Recommended Structure

- `ecommerce-1.jpg`, `ecommerce-2.jpg`, `ecommerce-3.jpg` - E-Commerce App screenshots
- `weather-1.jpg`, `weather-2.jpg` - Weather App screenshots
- `task-1.jpg`, `task-2.jpg`, `task-3.jpg` - Task Management App screenshots
- `social-1.jpg`, `social-2.jpg` - Social Media App screenshots
- `fitness-1.jpg`, `fitness-2.jpg`, `fitness-3.jpg` - Fitness Tracker screenshots
- `news-1.jpg`, `news-2.jpg` - News Reader App screenshots

## Image Guidelines

- **Format**: JPG or PNG
- **Recommended Size**: 1080x1920px (portrait) or 1920x1080px (landscape)
- **File Size**: Keep under 500KB per image for optimal loading
- **Naming**: Use lowercase with hyphens (e.g., `project-name-1.jpg`)

## Usage

Reference screenshots in `src/data/projects.js`:

```javascript
screenshots: [
  "/screenshots/ecommerce-1.jpg",
  "/screenshots/ecommerce-2.jpg",
]
```
